# dsdst-operations

Production orchestration, operational runbooks, and cross-application tests for DSDST Operations v1, including Customer Hub. Application source code stays in its own repositories.

Start with [deployment](docs/deployment.md), review the [architecture](docs/architecture.md), configure [CI/CD and branch protection](docs/ci-cd.md), and rehearse [disaster recovery](docs/disaster-recovery.md).

Hardening release provenance is defined by the redacted [release evidence contract](docs/release-evidence.md). A repository checkout SHA is not runtime evidence.
